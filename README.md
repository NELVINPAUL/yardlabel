Yard Labels — Sneaker Store

A self-contained, single-file HTML/CSS/JavaScript e-commerce site for sneakers, built for the Kenyan market with KES pricing, M-Pesa checkout simulation, and no backend or build tools required.

 Overview

Yard Labels is a full-featured sneaker storefront covering everything from Nike, Adidas, Jordan, and New Balance classics to Naked Wolfe–style cyber-streetwear (Balenciaga, Prada, Alexander McQueen) and Adidas Terrex–style rugged Gorpcore (Salomon, Hoka, Nike ACG). The entire site — markup, styles, and logic — lives in one `index.html` file.

 Features

- **388 product listings** — 97 shoe models × 4 categories (Men, Women, Kids, Unisex)
- **Size-based pricing** — price scales from ~KES 2,000 at size 37 up to KES 4,500–6,000 at size 45
- **Filters** — Category, Style (Classic / Cyber-Streetwear / Techwear-Gorpcore / Hybrid), Brand, Colour, and Price range
- **Sort options** — Popular, Newest, Price (low/high), Highest rated
- **3D shoe viewer** — drag-to-rotate product modal with auto-spin toggle
- **Colorway preview** — tap a color dot to tint the product image (Red / White / Blue)
- **Cart & checkout** — M-Pesa/card payment
